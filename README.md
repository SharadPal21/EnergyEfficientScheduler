# ⚡ CPU Scheduling Simulator (Python + Web)

A comprehensive **CPU Scheduling Simulator** that demonstrates core Operating System scheduling algorithms using both:

* 🖥️ Python CLI (Terminal-based simulator)
* 🌐 Interactive Web Application (Modern UI + Gantt Chart)

---

## 🚀 Live Demo

👉 **Web Version:**
https://SharadPal21.github.io/EnergyEfficientScheduler/cpu-scheduler-web/

---

## 🧠 Algorithms Implemented

* First Come First Serve (FCFS)
* Shortest Job First (SJF)
* Priority Scheduling
* Round Robin (RR)

---

## 💻 Features

### 🖥️ CLI Version (Python)

* Menu-driven interface
* User input via terminal
* Gantt Chart visualization using Matplotlib
* Calculates:

  * Average Waiting Time (AWT)
  * Average Turnaround Time (ATAT)

---

### 🌐 Web Version

* Modern responsive UI
* Add processes dynamically
* Select scheduling algorithm
* Interactive Gantt Chart (Chart.js)
* Real-time calculation of:

  * AWT
  * ATAT
